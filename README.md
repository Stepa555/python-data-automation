# Python Data Automation

Универсальный скрипт для загрузки, очистки и расчёта ключевых метрик коммерческих данных.

## Что умеет скрипт
- Загружает любой CSV-файл
- Автоматически определяет структуру данных
- Выводит список колонок для выбора
- Очищает данные от мусора и пропусков
- Считает ключевые метрики: выручка, средний чек, количество заказов
- Форматирует результат с округлением и разделителями тысяч

## Используемые библиотеки
- pandas
- google.colab (для загрузки файлов)

## Как запустить
1. Открой Google Colab
2. Загрузи файл `python_data_automation.ipynb`
3. Выполни все ячейки
4. Выбери нужный файл и колонку для анализа
